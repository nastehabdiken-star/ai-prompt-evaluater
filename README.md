# AI Prompt Quality Rating Portfolio

Hi, I'm Nasteha Abdi. This portfolio shows how I evaluate AI responses and write prompts, built for AI Prompt Quality Rater roles.

## What's inside

- **[Response comparisons](samples/)**: side-by-side ratings of two AI answers to the same prompt, scored on helpfulness, accuracy, clarity, and safety, with a written justification for each decision
- **[Rating rubric](rubric.md)**: my own 1 to 5 scale with a clear definition for each score, applied consistently across my samples
- **[Prompt improvement case study](prompt-case-study.md)**: a weak prompt, my improved version, and an explanation of what changed in the response
- **[Fact-check sample](samples/fact-check.md)**: an AI answer with each claim checked against reliable sources
- **[Data cleaning project](pandas-project/)**: a Python and pandas notebook that cleans a public CSV dataset, with before and after results

## How I work

- I read the prompt and the guidelines first, then judge each response against them.
- I explain every rating in plain, concise English so another reviewer can follow my reasoning.
- I check factual claims against sources instead of trusting how confident an answer sounds.
- All samples use my own prompts and public data.
