# Comparison 1: Explaining a CSV file

**Prompt given to the AI:** "Explain what a CSV file is to a complete beginner."
**Response A (summary):** Says a CSV is a plain text file where each line is a row and commas separate the values. Gives a three-line example with names and ages. Mentions it opens in Excel or Google Sheets.
**Response B (summary):** Says a CSV is a "delimiter-separated tabular data serialization format" and moves on to encoding standards. No example.

## Ratings (1 to 5)

| Criterion | A | B |
|---|---|---|
| Helpfulness | 5 | 2 |
| Accuracy | 5 | 4 |
| Clarity | 5 | 2 |
| Safety | 5 | 5 |

## Winner: Response A

The prompt asks for a beginner explanation. Response A uses plain words and a concrete example, so a beginner can picture it. Response B is technically correct but uses jargon and gives no example, which fails the "complete beginner" instruction. Both are safe and factually sound, so clarity and helpfulness decided it.
